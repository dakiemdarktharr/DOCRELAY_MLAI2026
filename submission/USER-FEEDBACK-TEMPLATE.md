# Phiếu ghi nhận người dùng

Mẫu trống, chưa có người tham gia hoặc kết quả đo. Tạo một bản cho mỗi phiên thực tế. Không công khai danh tính/quote nếu chưa có đồng thuận.

| Trường | Nội dung điền sau khi thử |
| --- | --- |
| Mã người tham gia | |
| Vai trò trực tiếp trong quy trình | |
| Tham chiếu hồ sơ danh tính/chức danh riêng cho BTC | |
| Ngày và tham chiếu đồng thuận | |
| Source SHA / policy / môi trường | |
| Task và tiêu chí thành công đã chốt | |
| Thứ tự trước/sau hoặc sau/trước | |
| Thời gian tổng trước / sau (giây) | |
| Thời gian chờ trước / sau (giây) | |
| Thời gian reviewer trước / sau (giây) | |
| Số lần hỏi thêm trước / sau | |
| Kết quả và người đánh giá | |
| Quote nguyên văn được phép sử dụng | |
| Bất lợi quan sát được / phạm vi chưa quan sát được | |
| Mức độ và biện pháp xử lý | |
| Quyết định thay đổi từ feedback | |
| Commit và kết quả kiểm tra lại | |

Không điền giá trị 0 cho dữ liệu chưa có. Dùng “chưa đo” hoặc “không áp dụng” kèm lý do.
