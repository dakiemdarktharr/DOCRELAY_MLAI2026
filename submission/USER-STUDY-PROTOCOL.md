# User study protocol — NOT COLLECTED

Recruit at least three consenting people representing a requester, a support/reviewer role and another relevant user. Do not invent names, roles, consent, quotations or participation. Keep consent records and contact details in an authorized private location, not this public repository. Publish only permitted anonymized findings using participant codes.

Before testing, freeze task wording, success criteria and safe synthetic inputs. Record baseline workflow and candidate source/policy. Counterbalance task order where possible. Use equivalent tasks before and after; record completion time, task success, number of clarifications, unnecessary handoffs and missed escalations with a reviewer-defined label. Separate a user's RESOLVED/CONFUSED choice from ground truth.

For every participant record role (self-described), consent reference, date actually performed, source versions, observed measurements and an exact approved quote. Record a concrete negative impact if observed (for example wasted time or a confusing refusal), its task context/severity and mitigation. Examples are protocol suggestions, not findings. If none is observed, say so and state the observation window; do not claim zero risk.

Map each actual feedback item to a decision: product change with file/commit reference, deferred change with reason, or no change. Retest changed behavior and retain the original observation. Do not attribute the current agent-found fixes to participant feedback.

Held-out evaluation uses independently reviewed labels frozen before model/runtime evaluation and intent groups disjoint from development. Reviewers must resolve disagreements. Report all three action classes, unavailable cases, sample sizes, confusion matrix, FNR/FPR, version and limits. A small study is descriptive evidence, not population-level accuracy.

Current evidence status: all participant observations, consented quotes, before/after measurements and negative-impact observations are NOT COLLECTED.
